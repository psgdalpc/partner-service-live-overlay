# Partner Service — Facebook Live Overlay

Overlay transparente 1920x1080 para OBS Studio.

## Estructura visual
- Pantalla compartida: X 44 / Y 150 / 1270x600
- Cámara: X 1335 / Y 150 / 440x265
- Comentarios: X 1335 / Y 445 / 440x305
- Tarjeta de presentador: X 1335 / Y 773 / 440x62
- Barra inferior: X 44 / Y 936 / 1832x118 aprox.

## Importante
El overlay dibuja los marcos, pero NO recorta las fuentes de OBS. En OBS hay que transformar/recortar la cámara y la captura para que coincidan con los huecos.

Los comentarios incluidos son demostrativos. Los comentarios reales de Facebook requieren una fuente/plugin/solución de comentarios independiente en OBS.
